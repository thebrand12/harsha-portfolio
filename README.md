# Harsha Creative Portfolio

Static HTML/CSS/JS portfolio for graphic design and video editing.

## Add videos
Place your MP4 files in `assets/videos/` and name them `reel-01.mp4`, `reel-02.mp4`, and `reel-03.mp4`. The video cards are configured for muted autoplay, looping, inline playback, and manual controls.

## Thumbnail gallery
Images are displayed with `object-fit: contain` so the complete 16:9 thumbnail remains visible without cropping.

## Run locally
Open `index.html` directly in a browser, or use VS Code Live Server if installed.
